# NerdSpace Labs - Streamer Mission Control Branding

Version: `0.8.0-alpha.4`

Streamer Mission Control uses the shared NerdSpace Labs visual system used across the Labs application family.

## Palette

| Role | Color |
| --- | --- |
| Background | `#000000` |
| Panel | `#0D0A14` |
| Raised panel | `#150F22` |
| Panel line | `#241B3A` |
| Control border | `#766595` |
| Main text | `#F1EDFB` |
| Muted text | `#948FB0` |
| Violet | `#8B5CF6` |
| Bright violet | `#A78BFA` |
| Deep violet | `#6D28D9` |

Red, amber, and green are reserved for semantic failure/warning/success states rather than decorative branding.

## Product mark

The application uses a text-first wordmark:

- `NERDSPACE LABS`
- `STREAMER MISSION CONTROL`

The splash screen contains only that product text, the desktop application icon, and a working/loading state.

## Icon

`Assets/app.png` and `Assets/app.ico` contain the same flat Sputnik-inspired satellite mark. The ICO is used for the Windows executable, taskbar, tray, shortcuts, and installer.

## Layout

- 10px panel radius
- 8px control radius
- thin violet borders
- black/purple surfaces
- restrained accent use
- no decorative orange branding
- text + icon status semantics rather than color alone
